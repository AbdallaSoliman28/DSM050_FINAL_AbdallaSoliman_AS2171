This repository contains the Jupyter Notebook and datasets used for the DSM050 Final Coursework project.

## Repository Structure

- `DSM050_FINAL_AbdallaSoliman_AS2171.ipynb`  
  Main notebook containing data preprocessing, analysis and visualisations.

- `datasets-for-final/Inter-StateWarData_v4.0.csv`  
  Correlates of War Inter-State War Data v4.0.

- `datasets-for-final/mpd2020.xlsx`  
  Maddison Project Database 2020.

- `data/ne_110m_admin_0_countries.zip`  
  Natural Earth country boundary data used for the choropleth map.

## Requirements

The analysis uses Python with the following packages:

- pandas
- numpy
- matplotlib
- openpyxl
- pyshp
- geopandas
- shapely

## Running the Notebook

1. Clone or download this repository.
2. Keep the existing folder structure unchanged.
3. Open `DSM050_FINAL_AbdallaSoliman_AS2171.ipynb`.
4. Run the notebook cells from top to bottom.

The notebook reads the economic and war datasets from the `datasets-for-final` folder and the Natural Earth geographic data from the `data` folder.
